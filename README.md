# RNT Fight — Solo

Five progressively harder CPU fights. A loss or draw ends the run. Five wins complete it. Each win scores 1,000 + remaining health × 10 + remaining seconds × 5. Personal best is saved only in the current browser/device.

Keyboard: A/D move, W jump, S crouch, J punch, K kick, L block. Touch controls included. No multiplayer server, bot token, telemetry, or shared leaderboard.

Publish this folder as a GitHub Pages repository; select main / root in Settings → Pages. Configure its HTTPS address in @BotFather as @RNTFightBot’s Main Mini App. The bot profile launch button/direct Mini App link opens this solo release. Command replies such as /fight require a separate bot backend and are not part of this static release.

Based on developerrutu/neon-fist (MIT, notice in LICENSE.txt). Original user-supplied roster artwork is separate and is not relicensed under MIT. Public hosting exposes the shipped game code and artwork.
